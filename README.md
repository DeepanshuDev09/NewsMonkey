# ​ NewsMonkey

A sleek and responsive **React** application that fetches and displays the latest news using the [NewsAPI](https://newsapi.org). Browse news by category and enjoy a seamless reading experience.

---

##  Features

-  Browse news from multiple categories: *General, Business, Entertainment, Health, Science, Sports, Technology*
-  Dynamic updates using **React hooks** and **async API calls**
-  Infinite scrolling or pagination for effortless browsing
-  Loading spinners to indicate content fetching in progress
-  Responsive design suitable for desktop and mobile devices
